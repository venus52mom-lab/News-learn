按 Safari 下方的「分享」→「加入主畫面」，再從桌面的 myTube 打開。這樣匯入的影片才會長期保存，不會被 Safari 自動清掉。 看圖文教學 ›

一次選很多個：點選檔案後，按右上角「打開」。

支援 PDF、Word（.docx）、EPUB、TXT。也可以貼電子書網址，或直接把整本內容貼上。

選一個影片或音樂，標出想要的片段（A→B、C→D、E→F…），可以排順序、合在一起。

從手機照片匯入，一張一張接起來，加轉場、文字、背景音樂，做成短影片或 PPT 簡報。

下載方式

畫質
a-Shell 手動指令（進階）

網路上的下載網站常被 YouTube 擋掉。這個方法用你自己手機的網路，比較不會被擋。只要設定一次：

1. App Store 安裝免費的 a-Shell，打開它，執行這兩行：

python3 -m pip install -U yt-dlp yt-dlp-apple-webkit-jsi
curl -sLo mt.py https://raw.githubusercontent.com/venus52mom-lab/News-learn/main/mytube/tools/mt.py

2. 以後要下載，在 a-Shell 執行：

python3 mt.py

貼上網址就會下載（下載時請停在 a-Shell，跳到 YouTube App 就按左上角「◀ a-Shell」回來）。會自動判斷：music.youtube.com 的連結下載成音樂，其他下載成影片（想把一般影片只存聲音，網址前面加 mp3）。檔案會在「檔案」App → a-Shell → myTube → 影片／音樂。

3. 回到 myTube，按「匯入手機檔案」，選剛下載的檔案（可以一次選很多個），myTube 會自動分到影片或音樂。

下載設定

已經內建 4 個下載服務，不填也能用；你加的會排在最前面優先使用。支援 cobalt 格式的 API，可以到 instances.cobalt.best 找 YouTube 標示可用的，把它的 API 網址貼上；也可以填自己架的 cobalt。

預設是 cobalt.meowing.de。如果這個網站下載 YouTube 失敗，可以換成其他下載網站的網址。
