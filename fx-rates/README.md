# 匯率走勢（個人用 iPhone App，不用上架）

仿 iOS「股市」的匯率看盤 App，資料來自**臺灣銀行牌告匯率**。

- 首頁：每個幣別一列，縮圖是近 3 個月走勢，右邊是最新牌價與漲跌（點一下切換：日漲跌 % / 3 個月 % / 漲跌值）
- 點進去：3個月 / 1年 / 3年 / 全部歷史，手指在圖上滑動可看每天數值；有最高/最低/平均與台幣換算
- 編輯：加入、移除、拖曳排序臺灣銀行有掛牌的 19 種外幣
- 設定：現金/即期、買入/賣出；「1 外幣 = ? 台幣」或「1000 台幣 = ? 外幣」；紅漲綠跌或綠漲紅跌

## 資料來源
- 今天／即時：玉山銀行官網牌告（玉山沒有的幣別或沒有現鈔價時，改用比率網上其他銀行）
- 2026/6/27 起的每日歷史：比率網每日歷史頁（優先玉山銀行）
- 2016/11 ~ 2026/6/26：比率網整理的臺灣銀行牌價（臺灣銀行網站本身會擋自動抓取）
- 走勢圖上的虛線＝資料來源換銀行的位置

## 怎麼運作
GitHub Actions「匯率 - 更新匯率」每個上班日 9:05–17:35 每 30 分鐘抓一次，存進 `data/`，GitHub Pages 提供給 App 讀。
iPhone 用 Safari 打開 https://venus52mom-lab.github.io/News-learn/fx-rates/ →「分享」→「加入主畫面」。
